# Football Manager 2.1 — Carreira Mundial (atualizado)

Abra o arquivo `index.html` em um navegador moderno (Chrome recomendado).

## Melhorias
- Modo de partida jogável: passe, avance, chute, defenda e encerre a partida.
- Relógio de jogo avança a cada ação, com gols, posse de bola e movimentação dos jogadores no campo.
- Elenco ampliado com mais estrelas e lendas do futebol.
- Estádio reage ao nível: iluminação visual, gramado e moldura mais destacados.
- Correções de segurança para dados salvos inválidos e jogadores removidos/fora do catálogo.
- Mantém carreira, contratações, treinos, melhorias, dificuldade e salvamento local.

O progresso é salvo no armazenamento local do navegador. Para começar uma partida, toque em **Jogar partida** e use os controles que aparecem.
